# Fantasy Football VR Website

A simple Flask website for FANTASY FOOTBALL VR.

## Run it

1. Install Python.
2. Open a terminal in this folder.
3. Install Flask:

   pip install -r requirements.txt

4. Start the website:

   python app.py

5. Open http://127.0.0.1:5000 in your browser.

## Files

- app.py - Python/Flask server
- templates/index.html - website page
- static/style.css - styling
- static/logo.png - supplied FANTASY FOOTBALL VR logo
